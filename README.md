# KeepItGreen — Πυροπροστασία Ακινήτων &amp; Ακάθαρτων Οικοπέδων

Επαγγελματική ιστοσελίδα για υπηρεσίες **πυροπροστασίας ακινήτων**, **καθαρισμού ακάθαρτων οικοπέδων**, **GIS**, **τηλεπισκόπησης** και **χαρτογράφησης με drone**.

**Powered By Athanasios Dim. Sapanidis**
MSc Forester – Environmentalist – GIS Analyst

## Υπηρεσίες

- Καθαρισμός ακάθαρτων οικοπέδων
- Πυροπροστασία ακινήτων / αντιπυρικές ζώνες
- Τεχνική έκθεση &amp; υπεύθυνη δήλωση συμμόρφωσης (ΚΥΑ 55904/2023, Π.Δ. 20/2024)
- Χαρτογράφηση με drone (Orthomosaic, 3D Elevation, NDVI, Hillshade)
- GIS &amp; χωρική ανάλυση
